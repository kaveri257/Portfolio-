# Kaveri Dhikale — Portfolio

Personal portfolio website showcasing my education, skills, projects, and certifications.

## About

I'm a B.Tech student in Artificial Intelligence & Data Science at K.K. Wagh Institute of Engineering Education and Research, Nashik. This site is where I share my background, work, and how to get in touch.

## Features

- Responsive layout (desktop, tablet, mobile)
- Smooth scroll animations
- Sections for About, Skills, Projects, Education, Certificates, Interests, and Contact
- Single-file build — no dependencies to install

## Built With

- HTML5
- [Tailwind CSS](https://tailwindcss.com/)
- [GSAP](https://gsap.com/) (ScrollTrigger)
- JavaScript (Canvas API)

## Getting Started

Clone the repo and open `index.html` in your browser:

```bash
git clone https://github.com/kaveri257/portfolio.git
cd portfolio
open index.html
```

Or run it with a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
